# 财务管理系统（单机版）

面向 ~100 人规模商贸公司的单机财务软件。**纯静态站：原生 HTML + JavaScript + localStorage，无构建、无依赖、无后端**。

- **怎么打开**：直接双击打开 `index.html` 即可运行（Chrome / Edge / Firefox 均可）；也可把整个目录托管到 GitHub Pages 或任意静态服务器后访问。全部数据保存在本机浏览器 `localStorage`（键 `finance-manager-v1`），不上传、无远程访问。
- 金额全程用整数"分"运算，避免浮点误差；显示时才转元。
- 科目编码规则 4-2-2（一级 4 位、二级 6 位、三级 8 位），只有末级科目可录凭证。
- 税率 / 扣除标准的唯一口径来源是根目录 `TAX_RULES_2026.md`，参数全部集中在 `js/taxrules.js`，其他模块只从 `window.FMTax` 取值，不得硬编码。

## 合规口径来源（TAX_RULES_2026.md）

- **增值税**（《增值税法》2026-01-01 施行）：一般纳税人 13% / 9% / 6%；小规模征收率 3%，2026-01-01 至 2027-12-31 减按 1%（销售/出租不动产、转让土地使用权除外）；月销售额 ≤ 15 万（季 ≤ 45 万）免征。
- **企业所得税**：法定 25%，高新 15%；小型微利企业（非限制行业 + 应纳税所得额 ≤ 300 万 + 从业人数 ≤ 300 + 资产总额 ≤ 5000 万）减按 25% 计入、按 20% 税率，**实际税负 5%**，执行至 2027-12-31，超 300 万全额不享受。
- **个人所得税**：起征点（减除费用）5000 元/月，7 级累计预扣率表；七项专项附加扣除（子女教育 2000、婴幼儿照护 2000、学历继续教育 400、职业资格证书 3600、住房贷款利息 1000、住房租金 1500/1100/800、赡养老人 3000/独生或 ≤1500 非独生、大病医疗超 15000 限 80000 仅汇算清缴扣）。
- **附加税**：城建税 7%（市区）/ 5%（县城镇）/ 1%，教育费附加 3%、地方教育附加 2%，计税依据为实缴增值税 + 消费税；小微"六税两费"减半至 2027-12-31。
- **其他**：折旧年限（房屋 20 / 设备 10 / 运输 4 / 电子 3 年，残值率默认 5%）；印花税（买卖合同 0.03%、借款合同 0.005%、营业账簿 0.025%）。

政策调整时只改 `js/taxrules.js` 并同步 `TAX_RULES_2026.md`。

## 单机版说明（已知限制）

- **存储**：全部数据在本机浏览器 localStorage（键 `finance-manager-v1`），不上传、无远程访问；清除浏览器数据 = 清空账套。“设置 → 恢复演示数据”按当前种子整库重建（旧数据自动备份到 `fm_backup_manual`）。
- **备份**：设置页“导出备份”下载 JSON 文件（含 seedVersion），换浏览器 / 换电脑靠它迁移；“导入备份”只接受当前种子版本的备份。
- **种子升级**：打开系统时若本地数据版本 ≠ 当前 `SEED_VERSION`，自动备份旧库（`fm_backup_<旧版本>`）后整库按当前种子重建——本地老数据不迁移数值（期初余额等种子内容随版本升级可能变化）。
- **单用户**：没有登录与多操作员，角色（管理员/会计/出纳/审计）用顶栏切换近似权限分工，审核约束用“制单人不能审核自己”近似；真实的多操作员、权限矩阵、远程协同需上服务器版。
- **性能边界**：凭证量按每年数千张、往来单位几十个设计；审计日志上限 5000 条自动截断。
